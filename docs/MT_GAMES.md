# 무혼 MT 이스터에그 — 개발 및 로컬 검증

> 기능 브랜치: `feat/mt-games-easter-egg` (base: `main`, `79b966690bb4144da0e9ea3ac64097fb77593495`).
> **운영 서버 미배포 / main 미병합 / 로컬 자동 검증 필요**

## 범위

- 기존 로그인 회원만 참여. MT 조와 기존 합주팀은 별개로 관리.
- `/my`의 이름을 빠르게 5회 터치하거나 `/mt` URL로 MT 홈 진입. 일반 메뉴·하단 내비게이션 변경 없음.
- 기본 행사 생성 시 8개 조와 문자 5문장 등록, 이후 조·문제는 자유롭게 관리.
- `/mt`에 접속하면 슈퍼관리자 또는 지정된 MT 관리자는 `/mt/host`로 자동 이동하고, 일반 회원은 참가자 화면을 본다.
- 슈퍼관리자는 `/mt/host/managers`에서 MT 관리자를 지정·해제한다. 합주 ADMIN 권한과 MT 관리자 권한은 별개다.
- MC 공개 스위치 OFF 시 참가자에게 게임명·문항 노출 없음. 기능을 꺼도 과거 기록은 유지.
- 버저: 조원 여러 명이 같은 조를 누를 수 있고, 서버에서 첫 요청만 인정. 열기·닫기·다른 조에 기회·재도전 허용·초기화.
- 버저 결과 확인 후 짧은 성공음과 지원 기기의 진동 (iOS Safari 진동 미지원/오디오 제한).
- 문자: 참가자 메신저형 화면, 하단 입력/전송 고정, 모든 전송 기록 열람, **마지막 제출만** 순위에 반영.
- MC 문장 자유 추가·편집·삭제·위/아래 이동; 제출 당시 정답 스냅샷은 그대로 유지.
- 문자 최종 상위 5명과 전체 제출(이름, 조, 내용, 정오, 최신/이전)을 MC에게 표시. 점수 계산 없음.
- 국기 이모지와 한글 조합은 서버에서 NFC 정규화 후 정확 비교. 띄어쓰기 및 문장부호는 일치 필요.
- 행사 종료 후 새 행사 생성 가능. 과거 행사는 기록 보관. 소프트 삭제된 조·문제는 당시 제출 기록을 유지.

## MT UX 단순화와 지난 MT 삭제 (2026-11-18)

- 문자·버저 외곽 카드 제거. 문자는 메시지 말풍선과 하단 입력만; 버저는 중앙 원형 `버저비터` 버튼만. 상태는 비활성화/색상으로 표현.
- MT 헤더 뒤로가기는 정해진 부모 경로, MT 안에서의 페이지 전환은 진입/복귀 방향 애니메이션 적용. 기존 합주 하위 페이지 전환 규칙은 유지.
- 운영 탭은 **공개된 게임만** 출력. 사용하지 않는 게임은 토글을 끄면 진행 메뉴에서 숨김. 운영 메뉴는 화살표 없이 공통 스타일로 표시; 문장 관리는 문자 게임 공개 시에만 보임.
- 지난 MT에서 종료된 행사만 영구 삭제 가능. 클럽 범위 확인 및 연결된 MT 조·문제·제출 기록 삭제, 행사명 입력 재확인. 삭제된 행사 복구 불가.
- 배경은 기존 작은 WebP 대신 밝은 유광 음영을 가진 `mt-emoji-sheet.svg`로 교체(확대 시 픽셀 깨짐 방지), 배치 수 12개.
- GitHub 단계에서 실제 Gradle·Vitest·Next 빌드/브라우저 테스트 미실행. 로컬 검증 후에만 운영 배포.

## 3D 배경 및 스위치 안정화 추가 (2026-11-18)

- 기존 반복 SVG를 제거하고 오리지널 3D 투명 WebP 스프라이트(`frontend/public/mt-emoji-sheet.webp`)로 교체. 웃는 얼굴, 별눈 얼굴, 파티콘, 풍선, 소주병·잔, 색종이가 서로 다른 크기·위치로 흩어지며 MT 경로에서만 렌더링.
- 배경 스타일을 `.mt-app-shell` 아래로 모두 제한하여 합주 예약 등 다른 페이지의 색상/배경 변경을 차단.
- MT 첫 로딩/권한 확인 시 빈 화면 대신 코랄색 접근성 스피너 표시, 숨겨진 MT 진입 시 쿼리 사전 요청.
- 공개 스위치는 해당 게임만 낙관적 갱신하고 단독 비활성화. 다른 버튼과 스위치를 함께 깜빡이게 만들던 공통 busy 처리에서 분리.
- 모든 페이지의 공통 헤더 제목에 선택 방지 추가. viewport에서 모바일 확대 제한 요청을 적용하되 브라우저/운영체제 접근성 예외는 보장할 수 없음.
- 새 기능은 소스 수준 점검만 시행. 프론트 테스트/lint/build 및 iOS·Android 화면 확인 전에는 main 병합 및 운영 배포 금지.

## MT 코랄 테마 · UX · 행사 기록

- MT 전용 코랄/피치 디자인. 기존 합주 화면에는 변경이 없다.
- 배경에는 반복 SVG로 입체 스마일·풍선·파티콘·색종이를 낮은 불투명도로 사용. 큰 행사 장식 카드는 제거한다.
- 참가자 MT 홈의 공개 게임 카드는 코랄/피치 채움형, 잠금 카드와 같은 높이. 상태 안내/화살표 없이 아이콘·제목만 표시. 잠긴 게임 정보는 드러나지 않는다.
- AppShell 공통 헤더의 뒤로가기·경로별 제목만 사용. MT 본문에서 중복 헤더를 제거.
- iOS 형태의 공개 스위치 ON 색상은 코랄. 관리자 지정 및 운영 메뉴도 코랄 스타일로 통일.
- MC가 버저를 직접 닫으면 V18 `buzzer_paused`를 true로 기록한다. 버저 성공 직후는 결과를 표시하다가 닫기 후에는 참가자 버튼이 회색 대기 상태로 변경된다.
- 문자 게임은 메시지 목록만 스크롤. 입력창·전송 버튼은 고정하고 키보드가 열리면 하단 내비게이션은 일시 숨긴다.
- `/mt/host/history` 지난 MT: 종료된 행사, 조/문제/제출 기록 조회 및 복구. 다른 활성 행사가 있을 때 복구를 막고 기록은 지우지 않는다.
- 복구 후 공개 스위치는 모두 OFF로 시작하며, 게임 진행 상태만 정지시킨다.
- Flyway V18은 신규 상태 컬럼만 추가한다. DB 초기화/삭제 작업 없음.

## 내부 구조

- **PostgreSQL Flyway V16**: `mt_events`, `mt_teams`, `mt_team_members`, `mt_buzzer_exclusions`,
  `mt_questions`, `mt_typing_rounds`, `mt_typing_submissions`.
- **Flyway V17**: 동아리별 `mt_host_managers` 지정 권한 테이블 추가. 기존 합주 권한은 변경하지 않는다.
- REST `/api/mt/**` — 기존 HttpOnly 인증 쿠키 사용. MC 작업은 지정된 MT 관리자 또는 슈퍼관리자만 가능하고, MT 관리자 지정·해제 API는 슈퍼관리자만 가능하다.
- 버저는 `SELECT ... FOR UPDATE`를 사용해 동시 요청을 직렬화. 판정 기준은 **서버 도착·처리 순서**, 손가락 터치의 물리적 선후는 보장하지 않음.
- UI는 참가자 0.65~1.1초, MC 1~1.2초 간격 상태 갱신을 사용함. 현재 버전에서 MT 전용 WebSocket 추가 없음.
- 기존 `/ws` 예약 실시간 구독이나 인증 설정은 변경하지 않음.
- 기존 DB와 예약·알림·PWA 운영 정책 변경 없음. V16은 신규 전진 마이그레이션.

## 수동 시나리오

1. 슈퍼관리자 `/mt` 자동 MC 이동, `MT 관리자 지정`에서 회원 지정·해제, 지정 회원 자동 MC 이동 및 미지정 회원의 MC API 차단 확인. 합주 ADMIN도 MT 지정 없이는 MC 접근 불가.
2. 관리자 로그인 → `/mt/host`에서 행사 생성. 스위치 OFF 상태 확인. 일반회원 `/mt`에는 잠금 문구만 표시.
2. 조 목록에서 조 추가/이름 변경/삭제, 회원 검색·배정·다른 조로 이동, 다른 조 재편성 확인.
3. 버저 ON → 일반회원이 배정된 조로 입장. 서로 다른 조/같은 조의 여러 기기로 거의 동시에 버저 누름 → 하나의 조만 획득.
4. MC 버저 닫기/열기, 다른 조에 기회, 재도전 허용, 초기화. UI에 다음 문제 버튼/정답 판정 버튼이 없어야 함.
5. 문자 ON → 문제 등록, 국기 이모지가 포함된 정답 입력, 참가자 2명 이상 동시 전송.
6. 한 회원이 오답 → 정답 → 오답을 보냄: 마지막 제출만 반영되어 순위에서 제외. 다시 정답을 보내면 새 접수 순서로 순위 복귀.
7. 참가자는 자신의 말풍선만 확인, MC는 이름·조·원문·정답 여부와 상위 5명을 확인.
8. 진행 중인 문장을 편집하면 거절되고, 종료 뒤에는 수정 가능하며 이전 결과가 유지되는지 확인.
9. iOS Safari 및 Android Chrome에서 한글 완성형/조합형과 🇰🇷 🇯🇵 등 국기 이모지 비교 확인. 키보드가 열릴 때 하단 입력창, 전송 버튼, 앱 내비게이션이 겹치지 않는지 확인.
10. 기존 홈/합주 예약/공지/알림/로그인 회귀 확인. 실패하면 main으로 병합하지 말 것.

## 현재 제한

- 이 GitHub-only 작업에서는 실제 Gradle/Next 빌드와 Docker/Testcontainers 및 모바일 UI 실측을 수행하지 못함.
- 성공음은 터치 제스처에서 오디오를 활성화할 수 있는 브라우저에서만 안정적이며 iPhone 웹 진동은 지원하지 않음.
- 화면은 짧은 주기 REST 갱신 방식이므로 접속자가 40명 정도일 때 실제 운영 서버 부하와 응답 지연을 사전 확인해야 함.
- 운영 배포는 미실시. 새 권한 기능을 확인하려면 API와 V16/V17 마이그레이션을 포함한 백엔드 배포가 필요하며, 개발자 검증 후 별도 승인 필요.
